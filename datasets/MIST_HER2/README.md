# MIST HER2 paired images

Unmodified MIST HER2 JPEGs and split from MAPS-GAN data archive commit `625bc17a502e611a494e0ab1e5b570efa3a347d9`, `data/MIST_HER2_TrainValAB`.

| Split | Images | Modality |
|---|---:|---|
| trainA | 4,642 | H&E, authors' training cohort |
| trainB | 4,642 | HER2 IHC, authors' training cohort |
| valA | 1,000 | H&E, authors' test cohort (archive folder name: valA) |
| valB | 1,000 | HER2 IHC, authors' test cohort (archive folder name: valB) |

The MIST authors report 4,642 HER2 training and 1,000 testing pairs; the upstream repository does not list a separate validation split. This MAPS-GAN archive uses `valA/valB` names for the 1,000-pair test cohort. Files are paired by shared source prefix and filename. `manifest.csv` lists original SHA-256 and bytes. The source prefix is not used as a patient identifier.

MorphoFlow-IHC preserves all 4,642 official training pairs and all 1,000 official test pairs. No separate validation split is provided by the MIST authors or generated by the loader. Keep the official test cohort untouched until final evaluation.

Images are Git LFS objects. Run `git lfs install` before cloning, or `git lfs pull` afterward. This archive contains HER2 only.
