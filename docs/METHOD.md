# Unpaired RGB flow and trajectory reward (experimental)

For real IHC target y and noise x0, flow matching uses xt=(1-t)x0+ty and target velocity y-x0. The U-Net's separate condition channels (RGB and support map) are zero in this term. Therefore its flow objective models the IHC target domain, not a supervised HE→IHC pairing; the target is present in xt by the definition of flow matching.

For an independently sampled HE h, a short H&E-conditioned rollout generates RGB. PatchNCE compares same-position features from h and that generated image, with within-image negatives. The patch encoder is trained jointly and its similarity is not ground-truth anatomical accuracy. A marker-conditioned patch discriminator is optimized on real IHC and generated RGB; the generator also receives the usual adversarial loss. Discriminator parameters have a separate optimizer and do not update during the generator backward pass. Original image size and marker are retained at inference; RGB tiles are blended.

A frozen discriminator and frozen patch encoder evaluate two H&E-conditioned candidate continuations sharing the same noise, prefix and sampled contrastive positions. The bounded reward is their mean: sigmoid(discriminator score) and exp(-PatchNCE/log(number of sampled positions)). It is not a cell-positivity reward. A clipped policy objective uses group-centred advantages scaled and clipped, bounded independent RGB-channel velocity residuals and KL rollback. These mechanisms do not prove stable convergence or prevent reward hacking. A marker must match the desired IHC domain; classification accuracy and positivity alignment require independent labels and evaluation.

The region branch still learns DAB support only within IHC, then receives projected HE features during inference. This is a domain adaptation assumption, not a validated pathology classifier. Training cache format 2 remains supported, whereas old checkpoints are intentionally rejected (format 3).

## Independently labeled expression units

The optional labeled protocol uses separate H&E and IHC case groups with a shared, explicitly declared binary endpoint per marker. The generator conditions on the frozen H&E scorer's predicted expression probability. The annotated expression label is used in the loss and reward during training. The IHC discriminator sees independently sampled images of the same marker and expression class. It compares distributions within each class, without learning pixelwise alignment. The target-domain flow term still regresses noise-to-IHC velocity without an input image condition. The H&E rollout receives PatchNCE, adversarial supervision and binary cross-entropy from the frozen IHC scorer. The legacy IHC-to-H&E region proxy is disabled for this protocol.

For a unit with label y and generated IHC score p, the policy endpoint score is 1 - (p - y)^2. It is averaged with the existing PatchNCE structure score. PPO and the differentiable control both sample two actions from the same Gaussian, with identical IHC scoring, structure scoring, velocity limits and KL rollback. PPO uses score-function updates. The control backpropagates through the sampled actions and their remaining Euler steps. The frozen IHC scorer can still be sensitive to artifacts. Evaluation needs a separate observed endpoint and independent structure metrics. Slide labels supply slide-level supervision and region labels supply region-level supervision. Cell-level localization requires its own evidence.
